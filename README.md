# Desktop pet 

A crow that walks across your screen and you can interact with

# How it works

- Walks across the screen
- randomly sits
- you can drag it and place wherever you like

# How it works (more detail)

when you open the program the crow  starts walking randomly sits and stands in place. You cal alter the crow position by garbing it with your mouse and dragging acros your screen, placing wherever you like
